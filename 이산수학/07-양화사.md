# 1. 왜 한정자(Quantifier)가 필요한가

## (1) 전제: 명제 함수는 아직 명제가 아니다

술어 논리에서

* (P(x)) 같은 형태는 **명제 함수(propositional function)** 입니다.
* 변수 (x)에 값이 정해지지 않았으므로 **참/거짓이 결정되지 않습니다.**
* 즉, **명제(proposition)**가 아닙니다.

예:
(P(x): x > 0) 라고 할 때

* (P(4)): “4 > 0” → 참
* (P(-3)): “-3 > 0” → 거짓
  하지만 (P(x)) 자체는 값이 없으니 참/거짓을 말할 수 없습니다.

## (2) 지금까지의 해결책: 값 대입

변수에 값을 대입하면 명제가 됩니다.

## (3) 새 해결책: 한정자로 “범위 전체”를 묶기

값을 하나 주는 대신,

* “모든 값에 대해” (∀)
* “어떤 값이 존재한다” (∃)

처럼 **도메인 전체를 대상으로 진리값을 결정**하게 합니다.

---

# 2. 한정자의 종류(영상에서 다룬 3개)

## (1) 전칭 한정자(Universal Quantifier) ∀

기호: (\forall) (거꾸로 A)

의미:
[
\forall x, P(x)
]
→ “도메인 안의 **모든 x에 대해** (P(x))가 참이다”

읽기:

* for all x, P(x)
* for every x, P(x)

---

## (2) 존재 한정자(Existential Quantifier) ∃

기호: (\exists) (거꾸로 E)

의미:
[
\exists x, P(x)
]
→ “도메인 안에 (P(x))를 참으로 만드는 **x가 적어도 하나 존재**한다”

읽기:

* there exists an x such that P(x)
* there is some x such that P(x)

---

## (3) 유일 존재 한정자(Uniqueness Quantifier) ∃!

기호: (\exists!)

의미:
[
\exists! x, P(x)
]
→ “도메인 안에 (P(x))를 참으로 만드는 x가 **정확히 하나만 존재**한다”

즉,

* 해가 **존재**하고(∃)
* 그 해가 **유일**해야 합니다(only one)

---

# 3. 도메인(Domain, Universe)이 왜 핵심인가

한정자는 항상 “어디에서 찾는가”가 붙습니다.

* 도메인이 정수인지, 자연수인지, 음의 정수인지에 따라
* 같은 식도 참/거짓이 달라집니다.

예: (P(x): x>0)

* 도메인 = 정수 (\mathbb{Z}) → (\forall x P(x)) 는 거짓 (반례 -3)
* 도메인 = 양의 정수 → (\forall x P(x)) 는 참

---

# 4. 전칭 한정자 ∀의 참/거짓 판정 규칙

## (1) ∀가 “참”이 되려면

[
\forall x, P(x)\ \text{가 참}
]
⇔ 도메인 안의 **모든 x**에 대해 (P(x))가 참

즉, 단 한 개라도 거짓이면 전체가 무너집니다.

## (2) ∀가 “거짓”이 되려면

[
\forall x, P(x)\ \text{가 거짓}
]
⇔ 도메인 안에 **반례(counterexample)**가 하나라도 존재
(= 어떤 x에 대해 (P(x))가 거짓)

### 실전 포인트: “거짓”은 반례 하나로 끝

전칭은 거짓임을 보일 때 **반례 1개**면 충분합니다.

---

## 예시 (영상)

(P(x): x>0)

### 도메인 = 정수 (\mathbb{Z})

* 반례: x = -3
* -3 > 0 은 거짓
  → (\forall x P(x)) 는 거짓

### 도메인 = 양의 정수

* 1,2,3,… 모두 0보다 큼
  → (\forall x P(x)) 는 참

(엄밀한 “증명”은 별도 도구가 필요하지만, 개념적으로는 이 구조가 핵심입니다.)

---

# 5. 존재 한정자 ∃의 참/거짓 판정 규칙

## (1) ∃가 “참”이 되려면

[
\exists x, P(x)\ \text{가 참}
]
⇔ 도메인 안에 (P(x))를 참으로 만드는 x가 **최소 1개 존재**

### 실전 포인트: “참”은 예시 하나로 끝

존재는 참임을 보일 때 **예시 1개**면 충분합니다.

## (2) ∃가 “거짓”이 되려면

[
\exists x, P(x)\ \text{가 거짓}
]
⇔ 도메인 안의 **모든 x**에 대해 (P(x))가 거짓
(즉, 가능한 모든 값이 실패해야 함)

---

## 예시 (영상)

(P(x): x>0)

### 도메인 = 정수 (\mathbb{Z})

* 예시: x=7
* 7>0 참
  → (\exists x P(x)) 참

### 도메인 = 음의 정수

* 모든 음의 정수는 0보다 작음
  → “x>0”을 만족하는 값이 없음
  → (\exists x P(x)) 거짓

---

# 6. ∀와 ∃의 구조적 차이(영상의 ‘크로스’ 포인트)

영상에서 강조한 핵심은 이것입니다.

* ∀는 “AND(그리고)” 느낌
  [
  P(첫값) \land P(다음값) \land P(다음값)\land \cdots
  ]
  전부 참이어야 참

* ∃는 “OR(또는)” 느낌
  [
  P(첫값) \lor P(다음값) \lor P(다음값)\lor \cdots
  ]
  하나만 참이어도 참

그래서 참/거짓 조건이 “교차(criss-cross)”처럼 보입니다.

* ∀: 참 = 모두 참 / 거짓 = 하나라도 거짓
* ∃: 참 = 하나라도 참 / 거짓 = 모두 거짓

---

# 7. 연습 예제 1 (영상 해설)

도메인: 정수 (\mathbb{Z})
(P(x): x^2 > 0)

## (1) (\forall x, P(x)) ?

* 반례 찾기: x = 0
* 0² > 0 → 0 > 0 → 거짓
  → 전칭은 반례 하나면 거짓
  ✅ 따라서 (\forall x, (x^2>0)) 는 **거짓**

## (2) (\exists x, P(x)) ?

* 예시 찾기: x = 1
* 1² > 0 → 1 > 0 → 참
  → 존재는 예시 하나면 참
  ✅ 따라서 (\exists x, (x^2>0)) 는 **참**

---

# 8. 연습 예제 2 (영상 해설)

도메인: 정수 (\mathbb{Z})
(P(x): x^2 < 0)

## (1) (\forall x, P(x)) ?

* 반례: x = 0 또는 x = 1
* 1² < 0 → 1 < 0 → 거짓
  → 전칭 거짓
  ✅ 따라서 **거짓**

## (2) (\exists x, P(x)) ?

* 정수에서 제곱은 0 이상
* 따라서 x² < 0 을 만족하는 정수는 없음
  → 존재 거짓
  ✅ 따라서 **거짓**

여기서 중요한 직관:

* 정수(더 넓게 실수)에서 “제곱”은 음수가 될 수 없습니다.

---

# 9. 연습 문제 (영상 해설)

도메인: 정수 (\mathbb{Z})
(P(x): x+1 = 2x)

## (1) (\exists x, P(x)) ?

방정식을 풀면:

* x+1 = 2x
* 1 = x
* x=1 (정수)
  → 해가 존재
  ✅ 존재는 참

## (2) (\forall x, P(x)) ?

모든 정수에 대해 성립하나?

* 반례: x=3
* 3+1 = 2·3 → 4=6 거짓
  → 전칭 거짓
  ✅ 전칭은 거짓

---

도메인: 정수 (\mathbb{Z})
(P(x): x^2 < 16)

## (1) (\exists x, P(x)) ?

예시: x=3

* 3²=9 < 16 참
  ✅ 존재 참

## (2) (\forall x, P(x)) ?

반례: x=5

* 5²=25 < 16 거짓
  ✅ 전칭 거짓

---

# 10. 유일 존재 한정자 ∃! (정확히 하나)

## (1) 의미 재정리

[
\exists! x, P(x)
]
= “P(x)를 만족하는 x가 **정확히 하나** 존재”

즉,

* 0개면 거짓
* 2개 이상이면 거짓
* 1개면 참

---

## 예시 (영상)

도메인: 정수 (\mathbb{Z})

### (1) (P(x): 2x = 4)

* x=2
* 해가 1개뿐
  ✅ (\exists! x) 참

### (2) (P(x): 2x > 4)

* x>2
* 정수 해가 무한히 많음(3,4,5,…)
  ❌ “유일”하지 않음
  ✅ (\exists! x) 거짓

### (3) (P(x): 2x = 3)

* x = 1.5
* 하지만 도메인은 정수
* 정수 해가 0개
  ✅ (\exists! x) 거짓

---

# 11. 실전 판단 요령(업무적으로 정리)

문제에서 “진리값을 구하라”가 나오면 다음 순서로 처리하면 안정적입니다.

1. **도메인 확인** (정수/자연수/실수/특정 집합)
2. (P(x))의 의미를 정확히 해석
3. ∀ 인지 ∃ 인지 ∃! 인지 확인
4. 판정 전략 적용

   * ∀ 거짓: **반례 1개**
   * ∃ 참: **예시 1개**
   * ∃ 거짓: **전부 실패** 구조 설명
   * ∃! 참: **정확히 1개**임을 확인
