

# 1. 왜 명제 논리(Propositional Logic)는 한계가 있는가

지금까지 다룬 명제 논리는 다음과 같은 특징을 가집니다.

* 하나의 문장은 **참(True) 또는 거짓(False)** 중 하나
* 문장 내부 구조는 고려하지 않음
* P, Q, R 같은 기호로 **문장 전체**를 표현

### 문제점이 드러나는 예시

> “모든 초콜릿이 들어간 사탕은 맛있다.”
> “M&M’s는 초콜릿이 들어간 사탕이다.”
>
> ⇒ “M&M’s는 맛있다.”

이 추론은 **논리적으로 타당해 보이지만**,
기존의 명제 논리로는 다음과 같은 이유로 표현할 수 없습니다.

* “모든 ~는 …이다”라는 **일반화**
* 대상(M&M’s)과 성질(맛있다)의 **관계**
* 변수 개념의 부재

👉 즉, **명제 논리는 개별 문장 간의 연결은 가능하지만,
대상과 성질의 구조적 관계를 표현할 수 없습니다.**

이 문제를 해결하기 위해 등장한 것이 **술어 논리(predicate logic)**입니다.

---

# 2. 술어 논리의 핵심 구성 요소

술어 논리는 최소한 다음 **두 가지**, 보통은 **세 가지 요소**로 구성됩니다.

1. **변수 (Variable)**
2. **술어 (Predicate)**
3. **한정자 (Quantifier)** ← 다음 영상에서 다룸

이번 설명에서는 **1번과 2번**에 집중합니다.

---

# 3. 변수(Variable)란 무엇인가

변수는 우리가 수학이나 프로그래밍에서 늘 사용하는 개념입니다.

### 예시

* x < 2
* x + y = z

이 문장들의 특징:

* 문장 형태는 갖췄지만
* **x, y, z에 값이 주어지지 않으면 참·거짓을 판단할 수 없음**

즉, 이런 문장은 아직 **명제(proposition)가 아님**.

---

# 4. 술어(Predicate)의 개념

### 핵심 정의

> **술어란, 변수에 대해 어떤 성질이나 관계를 서술하는 부분**

### 예시:

“x는 2보다 작다”

* 변수: x
* 술어: “2보다 작다”

이때:

* x = 5 → “5는 2보다 작다” → 거짓
* x = 1 → “1은 2보다 작다” → 참

👉 **값이 주어져야 비로소 참·거짓이 결정**됩니다.

---

# 5. 술어는 함수처럼 표현된다

술어 논리에서는 다음과 같이 표기합니다.

[
P(x)
]

* P: 술어 (성질 또는 관계)
* x: 변수

이 표기법은 **함수와 매우 유사**합니다.
그래서 이를 **명제 함수(Propositional Function)**라고 부릅니다.

---

# 6. 명제 함수(Propositional Function)

### 정의

> 명제 함수란,
> **변수가 포함되어 있어 아직 참·거짓이 결정되지 않은 논리식**

즉,

* **명제 함수 ≠ 명제**
* 명제가 되려면 반드시:

  1. 변수에 값을 대입하거나
  2. 한정자로 변수를 묶어야 함

---

## 예시 1: 단일 변수 명제 함수

[
P(x): x > 0
]

* P(-3): -3 > 0 → 거짓
* P(0): 0 > 0 → 거짓
* P(3): 3 > 0 → 참

👉 **값을 대입한 순간 명제가 된다**

---

# 7. 정의역(Domain) 또는 우주(Universe)

변수에 어떤 값이 들어올 수 있는지는 매우 중요합니다.

이를 **정의역(domain)** 또는 **우주(universe)**라고 합니다.

### 예시

* 정수 전체
* 자연수
* 실수
* 사람 집합
* 학생 집합 등

보통 **U**로 표기합니다.

⚠️ 정의역이 달라지면 **같은 술어라도 의미가 완전히 달라질 수 있음**

---

# 8. 다변수 술어의 예

### 예시 술어

[
R(x, y, z): x + y = z
]

* 술어: R
* 변수: x, y, z
* 정의역: 정수 전체

---

## (1) 값이 모두 주어진 경우 → 명제

### R(2, −1, 5)

* 2 + (−1) = 1
* 1 ≠ 5 → **거짓**

### R(3, 4, 7)

* 3 + 4 = 7
* 7 = 7 → **참**

---

## (2) 값이 일부만 주어진 경우 → 여전히 명제 함수

### R(x, 3, z)

* x와 z에 값이 없음
* 참·거짓 판단 불가
* **명제 함수 상태 유지**

---

# 9. 술어 논리에서도 논리 연산자는 그대로 사용된다

아주 중요한 점입니다.

> **명제 논리에서 배운 모든 연결사(¬, ∧, ∨, →)는
> 술어 논리에서도 동일하게 적용됩니다.**

---

## 예시: 복합 표현식

[
P(3) \lor P(-1)
]

만약
[
P(x): x > 0
]

이라면:

* P(3): 참
* P(-1): 거짓
* 참 ∨ 거짓 → **참**

👉 구조만 복잡해졌을 뿐,
**논리 연산 규칙은 완전히 동일**

---

# 10. 매우 중요한 핵심 문장 (시험·실무 공통)

> **변수가 포함된 표현식은
> 값이 주어지기 전까지는 명제가 아니며
> 참·거짓을 갖지 않는다.**

이를 해결하는 방법은 오직 두 가지입니다.

1. 변수에 **구체적인 값을 대입**
2. 변수를 **한정자(∀, ∃)**로 묶기
   → 다음 영상에서 다룸
