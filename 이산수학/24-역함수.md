# 1. 역함수(Inverse Function)란 무엇인가?

## 핵심 아이디어

> **역함수는 원래 함수가 한 일을 정확히 되돌리는 함수**다.

* 원래 함수가
  [
  x \mapsto y
  ]
  라면,

* 역함수는
  [
  y \mapsto x
  ]

즉, **입력과 출력을 뒤집는다**.

---

## 1.1 왜 ‘전단사(bijective)’여야 하는가?

역함수가 존재하려면 반드시 함수가 **전단사**여야 한다.

### 이유를 분해해서 보면

### (1) 일대일(injective)이어야 하는 이유

* 하나의 출력값에 여러 입력이 매핑되면
  → 거꾸로 갈 때 **어디로 돌아가야 할지 결정 불가**

### (2) 전사(surjective)여야 하는 이유

* 공역에 사용되지 않는 값이 있으면
  → 그 값에서는 **역함수가 정의되지 않음**

따라서:

> **역함수 ⇔ 전단사 함수**

---

## 1.2 역함수의 표기

* 함수: ( f : A \to B )
* 역함수: ( f^{-1} : B \to A )

⚠️ 주의
( f^{-1} )은 **1/f가 아니다**.
지수 −1은 “역함수”라는 **기호**일 뿐이다.

---

## 2. 역함수의 직관적 이해 (매핑 그림 관점)

원래 함수가

* 1 → 6
* 2 → 7
* 3 → 5
* 4 → 8

이라면, 역함수는

* 6 → 1
* 7 → 2
* 5 → 3
* 8 → 4

즉,

> **화살표 방향만 완전히 뒤집는다**

---

# 3. 예제 1: 함수가 역함수를 가지는가?

### 주어진 함수

* 정의역: {a, b, c}
* 공역: {1, 2, 3, 4}
* 대응:

  * f(a) = 1
  * f(b) = 3
  * f(c) = 4

### 판단 절차

#### (1) 일대일?

* 출력값이 겹치지 않음 → ⭕ 일대일

#### (2) 전사?

* 공역의 2가 사용되지 않음 → ❌ 전사 아님

### 결론

> **전단사가 아니므로 역함수 존재 ❌**

---

# 4. 예제 2: ( f(x) = x + 3 ),  ℤ → ℤ

## 4.1 전단사 여부 확인

### (1) 일대일 확인

[
f(a) = f(b) \Rightarrow a + 3 = b + 3 \Rightarrow a = b
]
→ ⭕ 일대일

### (2) 전사 확인

임의의 정수 y에 대해
[
x = y - 3
]
을 선택하면 항상
[
f(x) = y
]
→ ⭕ 전사

### 결론

> **전단사 ⇒ 역함수 존재**

---

## 4.2 역함수 구하는 방법 (실전 절차)

### Step 1. y로 바꾸기

[
y = x + 3
]

### Step 2. x와 y 역할 교체

[
x = y + 3
]

### Step 3. y에 대해 풀기

[
y = x - 3
]

### 최종 결과

[
f^{-1}(x) = x - 3
]

### 직관 확인

* f는 +3
* 역함수는 −3
  → 정확히 “되돌림”

---

# 5. 합성함수(Composition of Functions)

## 정의

두 함수 (f, g)에 대해

[
(g \circ f)(x) = g(f(x))
]

말로 하면:

> **먼저 f를 적용하고, 그 결과에 g를 적용**

---

## 5.1 중요한 규칙: 안쪽부터 계산

[
g(f(x)) \quad \text{→ f 먼저, g 나중}
]

이 순서를 틀리면 **완전히 다른 함수**가 된다.

---

# 6. 합성함수 예제

### 주어진 함수

* ( f(x) = x + 3 )
* ( g(x) = x^2 - 2 )

---

## 6.1 ( (f \circ g)(x) )

### 계산

[
f(g(x)) = f(x^2 - 2) = (x^2 - 2) + 3 = x^2 + 1
]

### 값 확인

[
(f \circ g)(1) = 1^2 + 1 = 2
]

---

## 6.2 ( (g \circ f)(x) )

### 계산

[
g(f(x)) = g(x + 3) = (x + 3)^2 - 2
]

전개하면:
[
x^2 + 6x + 9 - 2 = x^2 + 6x + 7
]

### 값 확인

[
(g \circ f)(1) = 1^2 + 6 + 7 = 14
]

---

## 6.3 중요한 결론

[
f \circ g \neq g \circ f
]

합성함수는 **교환법칙이 성립하지 않는다**.

---

# 7. 역함수와 합성함수의 관계 (아주 중요)

전단사 함수 (f)에 대해:

[
f(f^{-1}(x)) = x
]
[
f^{-1}(f(x)) = x
]

즉,

> **서로를 합성하면 항등함수(identity function)가 된다**
