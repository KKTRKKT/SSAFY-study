# 1. 이번 영상의 목표: “번역 + 부정 + 재번역”을 한 세트로 다루기

술어 논리에서 한정자가 들어가면 다음 작업이 자주 요구됩니다.

1. 영어 문장 → 술어 논리식(한정자 포함)
2. 그 논리식을 **부정**
3. 부정된 논리식을 다시 영어로 번역

이 과정에서 가장 중요한 것은:

* **도메인(정의역)** 설정
* **명제함수(술어)** 정의
* **한정자 부정 규칙(드모르간)** 적용
* 번역 시 “not every” / “there exists … not” 같은 자연어 형태를 정확히 쓰기

---

# 2. 복습: 우리가 주로 쓰는 두 한정자

## (1) 전칭 한정자 ∀ (for all)

[
\forall x, P(x)
]
의미: 도메인에 속한 **모든 x에 대해** P(x)가 참

예시(영상):

* (P(x)): “x는 프로그래밍 과목을 수강했다”
* 도메인: “우리 반 학생”

[
\forall x, P(x)
]
→ “우리 반 **모든 학생**은 프로그래밍 과목을 수강했다”

---

## (2) 존재 한정자 ∃ (there exists)

[
\exists x, P(x)
]
의미: 도메인에 속한 x 중 **적어도 하나**는 P(x)가 참

같은 설정에서:
[
\exists x, P(x)
]
→ “우리 반 학생 중 **누군가는** 프로그래밍 과목을 수강했다”

---

# 3. 한정자 부정: 드모르간 법칙(Quantifiers 버전)

이 부분이 영상의 핵심입니다. 아래 두 줄은 **암기 대상**입니다.

## (1) 전칭의 부정

[
\lnot (\forall x, P(x)) \equiv \exists x, \lnot P(x)
]

자연어로:

* “모든 x가 P이다”의 부정은
  → “P가 **아닌 x가 하나는 존재**한다”

즉,

* “모든 학생이 수강했다”의 부정 = “수강하지 않은 학생이 있다”

---

## (2) 존재의 부정

[
\lnot (\exists x, P(x)) \equiv \forall x, \lnot P(x)
]

자연어로:

* “P인 x가 존재한다”의 부정은
  → “모든 x가 P가 아니다”

즉,

* “수강한 학생이 있다”의 부정 = “모든 학생이 수강하지 않았다”

---

# 4. 예제 1: “There is an honest politician.”

## Step 1) 번역 준비: 도메인과 술어 정의

영상은 이렇게 단순화합니다.

* 도메인: 정치인 전체
* (H(x)): “x는 정직하다”

그러면 “정직한 정치인이 있다”는:
[
\exists x, H(x)
]

---

## Step 2) 부정하기

[
\lnot(\exists x, H(x)) \equiv \forall x, \lnot H(x)
]

---

## Step 3) 부정된 문장 영어로 번역

[
\forall x, \lnot H(x)
]
→ “모든 정치인은 정직하지 않다”
→ 더 자연스럽게: “모든 정치인은 부정직하다”

여기서 자연어 주의점:

* “모든 정치인이 정직하지 않다”는 의미상 “정치인 전부가 부정직”에 해당합니다.
* 반면 “정치인 모두가 정직한 것은 아니다”는 **약한 부정**(not all)이라서 의미가 다릅니다.

  * not all = (\lnot \forall x H(x)) = (\exists x \lnot H(x))

즉, 표현을 정확히 구분해야 합니다.

# 5. 예제 2: “All Americans eat cheeseburgers.”

## Step 1) 번역 준비

* 도메인: 미국인 전체
* (C(x)): “x는 치즈버거를 먹는다”

[
\forall x, C(x)
]

## Step 2) 부정하기

[
\lnot(\forall x, C(x)) \equiv \exists x, \lnot C(x)
]

## Step 3) 영어로 번역

[
\exists x, \lnot C(x)
]
→ “치즈버거를 먹지 않는 미국인이 있다”
→ “모든 미국인이 치즈버거를 먹는 것은 아니다”

이게 전칭의 부정이 자연어에서 흔히 나오는 패턴입니다.

# 6. 번역이 어려워지는 이유: 도메인(정의역)이 바뀌면 논리식 구조가 달라진다

영상이 아주 중요한 포인트를 짚습니다.

같은 영어 문장이라도,

* 도메인을 좁게 잡으면 식이 간단해지고
* 도메인을 넓게 잡으면 “그중에서 조건을 만족하는 대상만”을 골라야 하므로 식이 복잡해집니다.

---

## 예제: “Some student in this class has visited Mexico.”

### 경우 A) 도메인 = “이 반 학생”

* (M(x)): “x는 멕시코에 방문했다”

[
\exists x, M(x)
]

왜 이렇게 간단한가?

* “student in this class” 조건이 이미 도메인에 포함되어 있기 때문입니다.

---

### 경우 B) 도메인 = “모든 사람”

이제 “학생” 조건을 따로 걸어야 합니다.

* (M(x)): “x는 멕시코에 방문했다”
* (S(x)): “x는 이 반 학생이다”

그러면:
[
\exists x, (S(x) \land M(x))
]

의미:

* “세상 모든 사람 중에서, 이 반 학생이면서 멕시코에 방문한 사람이 존재한다”

여기서 괄호가 중요한 이유:

* (\exists x)가 (S(x))와 (M(x)) **둘 다**에 적용되어야 “같은 사람 x”에 대한 조건 결합이 됩니다.

---

# 7. 연습 문제(영상): “Every student in this class has visited Canada or Mexico.”

문장 구조:

* “Every …” → 전칭(∀)
* “visited Canada or Mexico” → ∨ (OR)

## 도메인 1) “이 반 학생”

영상의 방식대로 술어를 잡으면:

* (C(x)): x는 캐나다에 방문
* (M(x)): x는 멕시코에 방문
* 도메인: 이 반 학생

[
\forall x, (C(x) \lor M(x))
]

---

## 도메인 2) “모든 사람”

이 경우 “이 반 학생이면…” 조건을 따로 걸어야 해서 보통 **조건문(→)** 구조가 등장합니다.

* (S(x)): x는 이 반 학생
* (C(x)): x는 캐나다 방문
* (M(x)): x는 멕시코 방문
* 도메인: 모든 사람

자연어 의미는 사실상:

> “모든 사람에 대해, 만약 그 사람이 이 반 학생이라면 캐나다 또는 멕시코를 방문했다.”

그래서:
[
\forall x, (S(x) \rightarrow (C(x) \lor M(x)))
]

이 형태가 매우 표준적입니다.

# 8. 실전에서 가장 자주 틀리는 포인트 정리

## (1) “Not all”의 정확한 논리식

* “Not all X are P”
  [
  \lnot(\forall x P(x)) \equiv \exists x \lnot P(x)
  ]
  → “P가 아닌 x가 있다”

## (2) “No”의 정확한 논리식

* “No X are P”
  [
  \lnot(\exists x P(x)) \equiv \forall x \lnot P(x)
  ]
  → “모든 x가 P가 아니다”

## (3) 도메인을 넓게 잡으면 ‘학생’ 조건을 반드시 포함해야 함

* 도메인 = 학생 → 단순
* 도메인 = 모든 사람 → (S(x)) 같은 “필터”가 필요

## (4) 괄호가 의미를 결정한다

* (\exists x (S(x)\land M(x))) : 같은 x가 둘 다 만족
* ((\exists x S(x)) \land M(x)) : 완전히 다른 의미(대개 의도와 불일치)
