### 1. **집합의 동등성 (Set Equality)**

두 집합이 **동등**하다는 것은 그 집합들이 **같은 요소**를 가진다는 뜻입니다. 예를 들어, 집합 A = {0, 1, 3, 4}와 집합 B = {0, 1, 3, 4}는 동등한 집합입니다. 순서가 다르거나 중복된 요소가 있어도, **같은 요소들이 포함되면** 두 집합은 동등하다고 말할 수 있습니다.

* 예시: 집합 A = {0, 1, 1, 3, 4, 4}와 집합 B = {0, 1, 3, 4}는 동등한 집합입니다.
* **중요한 점**: 요소의 중복이나 순서는 중요하지 않지만, **집합 A에만 있는 요소**가 집합 B에 있지 않으면 동등하지 않습니다.

### 2. **부분집합 (Subset)**

집합 A가 집합 B의 **부분집합**이란, 집합 A의 모든 요소가 집합 B에도 포함되어 있을 때를 말합니다. 즉, 집합 A의 모든 요소가 집합 B에 있을 때 A는 B의 부분집합이 됩니다.

* 예시: A = {1, 2, 3}, B = {1, 2, 3, 4, 5}라면 A는 B의 부분집합입니다.
* **기호**: A ⊆ B (A는 B의 부분집합)

### 3. **부분집합 증명 (Proof of Subset)**

부분집합임을 증명하려면 집합 A의 **모든 요소**가 집합 B에도 속함을 보여야 합니다. 예를 들어, A = {1, 2, 3}가 B = {1, 2, 3, 4, 5}의 부분집합임을 증명하려면, 1, 2, 3이 모두 B에 포함되어 있음을 확인하면 됩니다.

* 반대로, A가 B의 부분집합이 아니라고 증명하려면, A의 어떤 요소가 B에 포함되지 않음을 찾으면 됩니다.

### 4. **진부분집합 (Proper Subset)**

**진부분집합**은 집합 A가 집합 B의 부분집합이지만, **두 집합이 동일하지 않음을** 의미합니다. 즉, A는 B의 일부이고, B에는 A에 없는 요소가 하나라도 있어야 진부분집합이 됩니다.

* 예시: A = {1, 2, 3}, B = {1, 2, 3, 4}라면 A는 B의 진부분집합입니다. B에는 A에 없는 4가 있기 때문입니다.
* **기호**: A ⊂ B (A는 B의 진부분집합)

### 5. **집합의 원소의 개수 (Cardinality)**

집합의 **카디널리티**는 집합에 포함된 **고유한 요소**의 수를 의미합니다. 예를 들어, 집합 A = {1, 2, 3, 3, 3, 4}의 카디널리티는 4입니다. 3이 중복되지만, 고유한 요소는 1, 2, 3, 4이므로 카디널리티는 4입니다.

* 예시: 집합 A = {a, b, c}의 카디널리티는 3입니다.
* 공집합의 카디널리티는 0입니다.

### 6. **멱집합 (Power Set)**

**멱집합**은 주어진 집합의 **모든 부분집합**을 모은 집합입니다. 예를 들어, 집합 A = {0, 1, 2}가 있을 때, A의 멱집합은 A의 모든 부분집합을 포함합니다:

* 집합 A = {0, 1, 2}의 멱집합은:

  * ∅ (공집합)
  * {0}, {1}, {2}
  * {0, 1}, {0, 2}, {1, 2}
  * {0, 1, 2}

A의 멱집합에는 총 8개의 부분집합이 있습니다 (2^n, 여기서 n은 집합 A의 원소 개수입니다). 따라서 A의 멱집합의 카디널리티는 8입니다.

### 7. **튜플 (Tuple)**

튜플은 **순서가 있는** 집합입니다. 보통 튜플은 **2개 이상의 요소**를 순서대로 나열한 것입니다. 예를 들어, (1, 2)는 순서가 중요한 두 요소의 집합으로, (2, 1)과는 다릅니다.

* **예시**: (1, 2)는 (2, 1)과 다릅니다. 순서가 중요하기 때문입니다.

### 8. **카르테시안 곱 (Cartesian Product)**

**카르테시안 곱**은 두 집합에서 각각 하나의 요소를 선택하여 **모든 가능한 순서쌍**을 만드는 방법입니다. 예를 들어, 집합 A = {0, 1}과 집합 B = {2, 3, 4}가 있을 때, A와 B의 카르테시안 곱은 다음과 같습니다:

* (0, 2), (0, 3), (0, 4)
* (1, 2), (1, 3), (1, 4)

카르테시안 곱은 **순서쌍**의 집합으로, A와 B의 각 요소를 짝지은 모든 가능한 쌍을 만듭니다.

### 9. **진리 집합 (Truth Set)**

**진리 집합**은 어떤 조건이 **참**이 되는 요소들의 집합입니다. 예를 들어, 조건이 "절댓값이 3인 숫자"라면, 진리 집합은 {-3, 3}이 됩니다.

* 예시: "절댓값이 3인 모든 정수"라는 조건의 진리 집합은 {-3, 3}입니다.

### 결론

이 내용은 집합 간의 관계를 이해하는 데 중요한 개념들입니다. 집합이 어떻게 동등한지, 부분집합이 무엇인지, 멱집합과 튜플 같은 개념들이 어떤 역할을 하는지 알면, 집합론을 더 쉽게 이해할 수 있습니다.
