## 1. 바닥 함수(Floor Function)와 천장 함수(Ceiling Function)

### 1-1. 바닥 함수 ⌊x⌋

* **정의**: 어떤 실수 (x)에 대해
  [
  \lfloor x \rfloor = x \text{보다 작거나 같은 정수 중 가장 큰 값}
  ]
* **직관**: “아래로 내린다(버린다)”라고 생각하면 된다.
* **예시**

  * (\lfloor 2.2 \rfloor = 2)
  * (\lfloor 5 \rfloor = 5)
  * (\lfloor 1/2 \rfloor = 0)

#### 음수에서의 주의점

* 수직선에서 **왼쪽이 작다**는 점을 반드시 기억해야 한다.
* 예:

  * (\lfloor -3.7 \rfloor = -4)
    (−4 ≤ −3.7 이고, −3은 −3.7보다 **크므로** 안 됨)

---

### 1-2. 천장 함수 ⌈x⌉

* **정의**: 어떤 실수 (x)에 대해
  [
  \lceil x \rceil = x \text{보다 크거나 같은 정수 중 가장 작은 값}
  ]
* **직관**: “위로 올린다”라고 생각하면 된다.
* **예시**

  * (\lceil 2.2 \rceil = 3)
  * (\lceil 5 \rceil = 5)
  * (\lceil -3.7 \rceil = -3)

#### 음수에서의 주의점

* “위로 간다”는 말은 **0 쪽으로 간다**는 의미가 아니다.
* 수직선에서 **큰 값 쪽**으로 간다고 이해해야 한다.

  * −3은 −3.7보다 크므로 천장값이 된다.

---

## 2. 팩토리얼 함수(Factorial Function)

### 2-1. 정의

* **기호**: (n!)
* **의미**: (n)이 **0 이상의 정수**일 때,
  [
  n! = n \times (n-1) \times (n-2) \times \cdots \times 1
  ]
* **특별한 약속**

  * (0! = 1)

### 2-2. 예시

* (4! = 4 \times 3 \times 2 \times 1 = 24)
* (3! = 6)
* (1! = 1)

### 2-3. 성질과 주의점

* 팩토리얼 값은 **아주 빠르게 커진다**.
* 그래서 큰 (n)에 대해서는 정확한 계산 대신 **근사식**을 사용하기도 하는데, 이를 **스털링 공식(Stirling’s Formula)**라고 한다.

  * 이 강의에서는 “존재만 알고 있으면 되는 수준”이다.

## 3. 바닥 함수가 포함된 함수 예제

### 3-1. 문제

함수:
[
f(x) = \left\lfloor \frac{x^2}{2} \right\rfloor
]

집합:
[
S = {0, 1, 2, 3}
]

각 원소에 대해 (f(x)) 값을 구하라.

---

### 3-2. 풀이 과정

#### (1) (f(0))

[
\frac{0^2}{2} = 0 \quad \Rightarrow \quad \lfloor 0 \rfloor = 0
]

#### (2) (f(1))

[
\frac{1^2}{2} = \frac{1}{2} = 0.5 \quad \Rightarrow \quad \lfloor 0.5 \rfloor = 0
]

#### (3) (f(2))

[
\frac{2^2}{2} = \frac{4}{2} = 2 \quad \Rightarrow \quad \lfloor 2 \rfloor = 2
]

#### (4) (f(3))

[
\frac{3^2}{2} = \frac{9}{2} = 4.5 \quad \Rightarrow \quad \lfloor 4.5 \rfloor = 4
]

---

### 3-3. 최종 결과

[
f(0), f(1), f(2), f(3) = \boxed{0,;0,;2,;4}
]

---

## 4. 핵심 정리

* **바닥 함수**: “작거나 같은 정수 중 최대”
* **천장 함수**: “크거나 같은 정수 중 최소”
* **음수에서 실수하기 쉬움** → 반드시 **수직선 기준**으로 생각
* **팩토리얼**: 정수에서만 정의, 곱셈이 누적되어 급격히 증가
* **바닥/천장 함수 문제 풀이 순서**

  1. 안쪽 식부터 계산
  2. 실수값 확인
  3. 바닥 또는 천장 적용
