### 1. **사례에 의한 증명 (Proof by Cases)**

**사례에 의한 증명**은 주어진 문제를 여러 가지 가능한 경우로 나누어 각 경우가 성립하는지를 검토하는 방법입니다. 예를 들어, "n이 정수라면 n ≤ n²"라는 명제를 증명한다고 할 때, n이 음수일 때, 0일 때, 양수일 때 각 경우를 따로 증명합니다.

#### 예시: `n ≤ n²` 증명

1. **첫 번째 경우**: n이 음수일 때 (n ≤ -1)

   * 음수는 제곱하면 양수가 됩니다. 예를 들어, -2를 제곱하면 4가 됩니다. 따라서 음수일 때는 항상 n ≤ n²이 성립합니다.

2. **두 번째 경우**: n이 0일 때

   * 0은 제곱해도 0입니다. 따라서 n ≤ n²이 성립합니다.

3. **세 번째 경우**: n이 양수일 때 (n ≥ 1)

   * 양수일 때 n²는 n보다 커지거나 같습니다. 예를 들어, 2는 제곱하면 4가 되고, 3은 제곱하면 9가 됩니다. 따라서 n ≤ n²이 성립합니다.

이렇게 각 경우를 따로 증명하여, 모든 경우에 대해 성립하는 것을 확인합니다. 이 방식은 "모든 경우를 고려했기 때문에 증명이 완전하다"는 확신을 줄 수 있습니다.

### 2. **사례에 의한 증명 (두 번째 예시)**

이번에는 **홀수**와 **짝수**의 성질을 이용한 증명입니다. "n이 짝수일 때, n² + 3n + 2는 짝수"임을 증명하려고 합니다.

* **첫 번째 경우**: n이 짝수일 때

  * 짝수는 2k 형태로 나타낼 수 있습니다. 이를 식에 대입하여 계산한 결과, n² + 3n + 2는 짝수입니다.

* **두 번째 경우**: n이 0일 때

  * 0을 대입하면 역시 짝수입니다.

* **세 번째 경우**: n이 홀수일 때

  * 홀수는 2k + 1 형태로 나타낼 수 있습니다. 이를 대입하고 계산하면 결과적으로 n² + 3n + 2는 짝수임을 확인할 수 있습니다.

### 3. **사례에 의한 증명 (세 번째 예시)**

세 번째 예시는 조금 더 복잡합니다. "x와 y가 모두 짝수라면 x + y도 짝수"라는 명제를 증명합니다.

여기서는 **모순을 이용한 증명** (Proof by Contradiction)도 사용합니다. "x와 y가 모두 짝수가 아니라면 x * y 또는 x + y 중 하나는 홀수일 것이다"라는 가정을 통해 증명합니다.

* **첫 번째 경우**: x가 홀수이고 y도 홀수일 때

  * x * y는 홀수이고 x + y는 짝수가 됩니다. 이 경우 x * y는 홀수로, 우리가 가정한 대로 하나는 홀수입니다.

* **두 번째 경우**: x가 홀수이고 y가 짝수일 때

  * x * y는 짝수이고 x + y는 홀수가 됩니다. 따라서 모순이 일어날 수 없다는 것을 보여줍니다.

### 4. **간략한 결론**

* **사례에 의한 증명**은 가능한 모든 경우를 고려하여 주어진 명제가 성립하는지를 따져보는 방식입니다.
* **모순을 이용한 증명**은 "만약 이 명제가 거짓이라면 다른 모순이 생길 것"이라는 방식으로 증명합니다.
* **'Without loss of generality'**는 여러 가지 경우가 동일한 결과를 낳는다는 사실을 이용하여 경우의 수를 줄이는 방법입니다.
