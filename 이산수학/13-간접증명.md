## 1. 간접증명의 개요

수학적 증명 방법은 크게 두 가지로 나뉩니다.

* **직접증명 (Direct Proof)**
* **간접증명 (Indirect Proof)**

이번 내용은 **간접증명 중 하나인 ‘대우에 의한 증명(Proof by Contraposition)’**에 관한 설명입니다.

---

## 2. 논리적 배경: 대우의 개념

어떤 명제가 다음과 같다고 하겠습니다.

> **명제**:
> If P, then Q
> (P이면 Q이다)

이 명제는 논리적으로 다음 명제와 **완전히 동치**입니다.

> **대우 (Contrapositive)**:
> If not Q, then not P
> (Q가 아니면 P도 아니다)

✔️ **중요한 사실**

* 원래 명제와 그 대우는 **항상 같은 참·거짓 값을 가집니다**.
* 따라서 대우가 참임을 증명하면, 원래 명제도 참입니다.

---

## 3. 대우에 의한 증명이란?

### 정의

**Proof by Contraposition**이란,

* `P → Q`를 직접 증명하지 않고
* 대신 `¬Q → ¬P`를 증명함으로써
* 원래 명제 `P → Q`가 참임을 보이는 방법입니다.

### 구조 비교

| 증명 방식 | 출발 가정      | 목표              |
| ----- | ---------- | --------------- |
| 직접증명  | P가 참       | Q를 증명           |
| 대우증명  | Q가 거짓 (¬Q) | P도 거짓 (¬P)임을 증명 |

---

## 4. 연습문제 1: 대우증명의 실제 적용

### 원래 명제

> **P**: (3n + 2) 는 홀수이다
> **Q**: (n) 은 홀수이다
>
> 즉,
> **If (3n+2) is odd, then (n) is odd**

---

### 1️⃣ 대우 설정

대우는 다음과 같습니다.

> **If (n) is not odd, then (3n+2) is not odd**

* not odd = **even (짝수)**

---

### 2️⃣ 가정 (¬Q)

> (n) 이 짝수라고 가정

짝수의 정의에 따라
[
n = 2k \quad (k는 정수)
]

---

### 3️⃣ 계산

[
3n + 2 = 3(2k) + 2 = 6k + 2 = 2(3k + 1)
]

* 이는 **2의 배수**
* 따라서 **짝수**

---

### 4️⃣ 결론

* (n) 이 짝수이면 (3n+2)도 짝수
* 즉, **¬Q → ¬P 성립**
* 따라서 **P → Q 성립**

✔️ 증명 완료 (QED)

---

## 5. 연습문제 2: 구조는 동일, 가정만 반대

### 이번 가정

> (n) 이 **홀수**라고 가정

홀수의 정의:
[
n = 2k + 1
]

---

### 계산

[
3n + 2 = 3(2k + 1) + 2
]
[
= 6k + 3 + 2 = 6k + 5
]
[
= 2(3k + 2) + 1
]

* 형태가 (2r + 1)
* 즉 **홀수**

---

### 결론

* (n) 이 홀수이면 (3n + 2)도 홀수
* 역시 **대우가 성립**
* 원래 명제도 참

---

## 6. Proof by Contraposition vs Proof by Contradiction

| 구분    | 대우에 의한 증명 | 모순에 의한 증명     |
| ----- | --------- | ------------- |
| 가정    | ¬Q        | P와 ¬Q를 동시에 가정 |
| 목표    | ¬P 증명     | 논리적 모순 도출     |
| 논리 구조 | 대우의 동치성   | 모순 → 거짓       |

이번 설명은 **대우에 의한 증명**이며,
다음 단계에서 **모순에 의한 증명(Proof by Contradiction)**을 다루게 됩니다.

---

## 7. 핵심 요약

* `P → Q`는 `¬Q → ¬P`와 논리적으로 동일
* 대우를 증명하면 원래 명제가 자동으로 증명됨
* 짝수/홀수 문제는 대우증명의 대표적인 연습 사례
* 계산은 항상 **정의(2k, 2k+1)** 에서 출발해야 함
