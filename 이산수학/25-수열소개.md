# 1. 수열(Sequence)이란 무엇인가

## 1-1. 기본 개념

* **수열(sequence)**이란
  👉 **정수 (n)**을 입력으로 받아 **값을 순서대로 나열한 것**
* 즉, 수열은 다음과 같은 형태를 가진다.
  [
  a_0, a_1, a_2, a_3, \dots
  ]

### 핵심 포인트

* **순서가 중요**하다.
* 각 항은 **번호(index)**를 가진다.
* 이 번호를 **아래첨자(subscript)**로 쓴다.

예:

* (a_n) : “n번째 항”
* (a_0) : 첫 번째 항 (이 강의에서는 대부분 0부터 시작)

---

## 1-2. 간단한 수열 예시

수열이 다음과 같이 정의되었다고 하자.
[
a_n = 2n
]

이 말의 의미는:

* “n번째 항은 (2 \times n)이다”

### 실제 값 계산

| n | 계산    | 값 |
| - | ----- | - |
| 0 | (2×0) | 0 |
| 1 | (2×1) | 2 |
| 2 | (2×2) | 4 |
| 3 | (2×3) | 6 |

👉 이 수열의 값들은
[
0,;2,;4,;6,;\dots
]

---

# 2. 등차수열 (Arithmetic Sequence)

## 2-1. 정의

* **등차수열**:
  👉 **항과 항 사이의 차이가 항상 같은 수열**
* 이 차이를 **공차(common difference)**라고 하며 (d)로 표시한다.

---

## 2-2. 구조로 이해하기

첫 항이 (a), 공차가 (d)라면:

* 첫 항: (a)
* 두 번째 항: (a + d)
* 세 번째 항: (a + 2d)
* 네 번째 항: (a + 3d)

즉,
[
a_n = a + dn
]

👉 이것을 **명시적 정의(explicit formula)**라고 한다.

---

## 2-3. 예제 ① — a와 d가 주어진 경우

* 첫 항 (a = 5)
* 공차 (d = 2)

### 명시적 정의

[
a_n = 5 + 2n
]

### 처음 5개 항

| n | 값  |
| - | -- |
| 0 | 5  |
| 1 | 7  |
| 2 | 9  |
| 3 | 11 |
| 4 | 13 |

---

## 2-4. 재귀적 방법 vs 명시적 방법

### 재귀적 정의 (recurrence)

* “**이전 항을 이용**해서 다음 항을 구함”
* 예:
  [
  a_{n} = a_{n-1} + 2
  ]

### 명시적 정의 (explicit)

* “**이전 항 없이도** n만 알면 바로 계산 가능”
* 예:
  [
  a_n = 5 + 2n
  ]

📌 **중요 차이**

* 재귀식 → 앞 항이 없으면 계산 불가
* 명시식 → n만 알면 바로 계산 가능

---

## 2-5. 예제 ② — 수열이 주어지고 a, d를 찾는 경우

수열:
[
7,;4,;1,;-2,;\dots
]

### 첫 항

* (a = 7)

### 공차

* (4 - 7 = -3)
* (1 - 4 = -3)
* (-2 - 1 = -3)

👉 공차 (d = -3)

### 명시적 정의

[
a_n = 7 - 3n
]

---

# 3. 등비수열 (Geometric Sequence)

## 3-1. 정의

* **등비수열**:
  👉 **항과 항 사이를 곱해서 같은 수가 나오는 수열**
* 이 값을 **공비(common ratio)**라 하고 (r)로 표시한다.

---

## 3-2. 구조로 이해하기

첫 항이 (a), 공비가 (r)라면:

* 첫 항: (a)
* 두 번째 항: (a r)
* 세 번째 항: (a r^2)
* 네 번째 항: (a r^3)

👉 일반항:
[
a_n = a r^n
]

---

## 3-3. 예제 ① — a와 r이 주어진 경우

* (a = 4)
* (r = 3)

### 명시적 정의

[
a_n = 4 \cdot 3^n
]

### 처음 5개 항

| n | 값   |
| - | --- |
| 0 | 4   |
| 1 | 12  |
| 2 | 36  |
| 3 | 108 |
| 4 | 324 |

---

## 3-4. 예제 ② — 수열이 주어지고 a, r을 찾는 경우

수열:
[
3,;\frac{3}{2},;\frac{3}{4},;\frac{3}{8},;\dots
]

### 첫 항

* (a = 3)

### 공비 구하기

[
r = \frac{\text{다음 항}}{\text{이전 항}}
= \frac{3/2}{3}
= \frac{3}{2} \times \frac{1}{3}
= \frac{1}{2}
]

### 명시적 정의

[
a_n = 3 \left(\frac{1}{2}\right)^n
]

📌 주의:

* (n)제곱은 **공비에만 적용**
* 앞의 3은 제곱되지 않는다

---

## 3-5. 공비가 1보다 작은 경우

* (0 < r < 1)이면 → **감소 수열**
* 항들이 점점 작아진다.

---

# 4. 등차수열 vs 등비수열 정리

| 구분    | 등차수열     | 등비수열    |
| ----- | -------- | ------- |
| 변화 방식 | 더한다      | 곱한다     |
| 핵심 값  | 공차 (d)   | 공비 (r)  |
| 일반항   | (a + dn) | (a r^n) |
| 찾는 방법 | 빼기       | 나누기     |
