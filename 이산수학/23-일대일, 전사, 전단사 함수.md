# 1. 기본 용어 정리 (반드시 짚고 가야 함)

함수를 이해하려면 아래 네 가지를 정확히 구분해야 한다.

| 용어                | 의미                                     |
| ----------------- | -------------------------------------- |
| **정의역 (Domain)**  | 입력값이 될 수 있는 모든 값                       |
| **공역 (Codomain)** | 출력값이 될 수 있도록 *미리 정해 놓은* 전체 집합          |
| **치역 (Range)**    | 실제로 출력으로 *나온 값들의 집합*                   |
| **함수 f**          | 정의역의 각 원소를 **정확히 하나의** 공역 원소에 대응시키는 규칙 |

> **중요한 차이**

* 치역 ⊆ 공역
* 공역 ≠ 치역일 수 있다

---

# 2. 일대일 함수 (Injective, One-to-One)

## 정의 (직관적)

> **서로 다른 입력은 서로 다른 출력으로 간다**

즉,

* 출력값 하나에 **입력이 하나만** 연결된다.

---

## 수학적 정의 (두 가지 표현)

### (1) 직접 정의

[
a \neq b \Rightarrow f(a) \neq f(b)
]

### (2) 대우(contrapositive) — 실제로 더 자주 씀

[
f(a) = f(b) \Rightarrow a = b
]

이 두 문장은 **논리적으로 완전히 동일**하다.

---

## 예시 1: 일대일인 경우

* A → 2
* B → 1
* C → 3

출력값(1,2,3)에 각각 **하나씩만** 연결됨
→ **일대일**

---

## 예시 2: 일대일이 깨지는 경우

* C → 3
* D → 3

출력값 3에 **두 개의 입력(C, D)**가 연결됨
→ ❌ 일대일 아님

---

## 핵심 판단 질문

> “같은 출력값으로 가는 서로 다른 입력이 존재하는가?”

* YES → 일대일 ❌
* NO → 일대일 ⭕

---

# 3. 전사 함수 (Surjective, Onto)

## 정의 (직관적)

> **공역의 모든 원소가 최소 한 번은 사용된다**

즉,

* 공역에 “남는 값”이 없어야 한다.

---

## 수학적 정의

[
\forall y \in \text{Codomain},\ \exists x \in \text{Domain} \text{ such that } f(x) = y
]

말로 쓰면:

> 공역의 임의의 y에 대해, y로 가는 x가 반드시 존재한다.

---

## 예시 1: 전사가 아닌 경우

* 공역: {1, 2, 3, 4}
* 실제로 도착한 값(치역): {1, 2, 4}

→ 3은 아무도 안 감
→ ❌ 전사 아님

---

## 예시 2: 전사인 경우

* D → 3 추가

이제 공역의 모든 원소(1,2,3,4)가
**최소 한 번 이상** 도달됨
→ ⭕ 전사

---

## 중요한 포인트

* **전사는 “겹쳐도 상관없다”**
* 같은 공역 값으로 여러 입력이 가도 문제 없음

---

# 4. 일대일 vs 전사 비교 정리

| 구분      | 기준            |
| ------- | ------------- |
| **일대일** | 출력 하나 ← 입력 하나 |
| **전사**  | 공역의 모든 값이 사용됨 |

---

# 5. 전단사 함수 (Bijective)

## 정의

> **일대일 + 전사** 를 동시에 만족하는 함수

즉,

* 출력값이 **겹치지 않고**
* 공역에 **남는 값도 없음**

---

## 직관적 표현

* “완벽한 1:1 대응”
* “일대일 대응(one-to-one correspondence)”

---

## 결과적으로 성립하는 성질

* 역함수(inverse function)가 **항상 존재**
* 가장 이상적인 함수 구조

---

# 6. 연습 문제 1 해설 (유한 집합)

### 주어진 함수

* X = {0,1,2,3}
* Y = {a,b,c}

| x | f(x) |
| - | ---- |
| 0 | c    |
| 1 | b    |
| 2 | b    |
| 3 | c    |

---

### (1) 일대일인가?

* b ← 1, 2
* c ← 0, 3

출력값이 겹침
→ ❌ 일대일 아님

---

### (2) 전사인가?

* 공역 Y = {a,b,c}
* a는 아무도 안 감

→ ❌ 전사 아님

---

### 결론

> **일대일도 아니고, 전사도 아님**

---

# 7. 연습 문제 2 해설 (무한 집합)

### 함수

[
f(x) = x^2,\quad \mathbb{Z} \to \mathbb{Z}
]

---

## (1) 일대일 여부

* f(2) = 4
* f(-2) = 4

출력 같음, 입력 다름
→ ❌ 일대일 아님

---

## (2) 전사 여부

* 공역: 모든 정수
* 하지만 제곱값은 **항상 0 이상**

예:

* -1, -3, -5 … 절대 나올 수 없음

→ ❌ 전사 아님

---

### 결론

> **일대일도 아니고, 전사도 아님**

---

# 8. 전체 요약 표

| 함수 유형               | 조건         |
| ------------------- | ---------- |
| **일대일 (Injective)** | 출력이 겹치지 않음 |
| **전사 (Surjective)** | 공역이 모두 사용됨 |
| **전단사 (Bijective)** | 위 둘 다 만족   |
| **역함수 존재**          | 전단사일 때만 가능 |
