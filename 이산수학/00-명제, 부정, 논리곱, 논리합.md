## 1. 명제(Proposition)란 무엇인가

**명제**란
👉 *참(True) 또는 거짓(False) 중 하나로 판단할 수 있는 선언문*입니다.

### ✔ 명제의 조건

* **선언문**이어야 한다
* **참 또는 거짓이 명확해야 한다**

### ✔ 명제의 예

* “하늘은 파랗다.” → 참/거짓 판단 가능 → **명제**
* “달은 치즈로 만들어졌다.” → 거짓 → **명제**
* “나는 네 아버지다.” → 참/거짓 가능 → **명제**

이런 명제들은 보통 **P, Q, R** 같은 **소문자 알파벳**으로 표현합니다.

---

### ❌ 명제가 아닌 경우

* **명령문**: “앉아라”
  → 참/거짓이 아님 → 명제 아님
* **미정인 수식**: `x + 1 = 2`
  → x 값이 정해지지 않음 → 참/거짓 판단 불가 → 명제 아님
  → 단, `x = 1` 이라고 주어지면 참이 되므로 **그때는 명제**

---

## 2. 논리 연산자(Connectives)

명제들을 결합하거나 변형하는 **연산자**입니다.
프로그래밍의 연산자(`+`, `&&`, `||`)와 같은 개념입니다.

| 이름      | 기호    | 읽는 법        | 의미        |
| ------- | ----- | ----------- | --------- |
| 부정      | ¬P    | not P       | P가 아니다    |
| 논리곱     | P ∧ Q | P and Q     | 둘 다 참     |
| 논리합     | P ∨ Q | P or Q      | 하나 이상 참   |
| 배타적 논리합 | P ⊕ Q | XOR         | 둘 중 하나만 참 |
| 조건문     | P → Q | if P then Q | P이면 Q     |
| 쌍조건문    | P ↔ Q | iff         | 참/거짓이 동일  |

이번 설명에서는 **부정, 논리곱, 논리합** 중심으로 다룹니다.

---

## 3. 부정(Negation, ¬P)

부정은 **명제의 참/거짓을 뒤집는 것**입니다.

### 예시

* P: “내 개는 가장 귀엽다” (참)
* ¬P: “내 개는 가장 귀엽지 않다” (거짓)

### 이중 부정

* P: “문이 열려 있지 않다”
* ¬P: “문이 열려 있다”
  → 수학에서는 **부정의 부정 = 원래 명제**

---

## 4. 진리표(Truth Table)

진리표는
👉 *모든 가능한 참/거짓 조합에 대해 결과를 정리한 표*입니다.

### ✔ 기본 원칙

* 명제가 **n개**면 → **2ⁿ개 행**
* 왼쪽: 모든 참/거짓 조합
* 오른쪽: 연산 결과

---

### 4-1. 부정의 진리표

| P | ¬P |
| - | -- |
| T | F  |
| F | T  |

의미:

* P가 참이면 ¬P는 거짓
* P가 거짓이면 ¬P는 참

---

## 5. 논리곱(Conjunction, P ∧ Q)

**AND 연산**
👉 *두 명제가 모두 참일 때만 참*

### 예시

* P: “비가 온다”
* Q: “집에 있다”
* P ∧ Q: “비가 오고, 나는 집에 있다”

### 진리표

| P | Q | P ∧ Q |
| - | - | ----- |
| T | T | T     |
| T | F | F     |
| F | T | F     |
| F | F | F     |

👉 **하나라도 거짓이면 전체가 거짓**

## 6. 논리합(Disjunction, P ∨ Q)

**OR 연산 (포함적 OR)**
👉 *하나라도 참이면 참*

### 예시

* “전공필수 과목 A 또는 B를 이수해야 한다”

  * A만 이수 → 가능
  * B만 이수 → 가능
  * 둘 다 이수 → 가능

### 진리표

| P | Q | P ∨ Q |
| - | - | ----- |
| T | T | T     |
| T | F | T     |
| F | T | T     |
| F | F | F     |

👉 **둘 다 거짓일 때만 거짓**

## 7. 배타적 논리합(XOR, P ⊕ Q)

**OR이지만 동시에 둘 다 참이면 안 됨**

### 예시

* “스프 또는 샐러드 제공”

  * 스프만 → 가능
  * 샐러드만 → 가능
  * 둘 다 → 불가

### 진리표

| P | Q | P ⊕ Q |
| - | - | ----- |
| T | T | F     |
| T | F | T     |
| F | T | T     |
| F | F | F     |

👉 **정확히 하나만 참일 때 참**

---

## 8. 핵심 정리

* **명제**: 참/거짓이 명확한 선언문
* **부정(¬)**: 참 ↔ 거짓 뒤집기
* **논리곱(∧)**: 모두 참이어야 참
* **논리합(∨)**: 하나라도 참이면 참
* **XOR(⊕)**: 하나만 참이어야 참
* **진리표**: 모든 경우를 체계적으로 검증하는 도구
