## 1. 진리표를 만드는 목적

진리표는 **복합명제의 참·거짓 값을 모든 경우에 대해 체계적으로 확인**하기 위한 도구입니다.
주된 활용 목적은 다음과 같습니다.

* 복합명제가 **항상 참인지(항진식)**, **항상 거짓인지**, **경우에 따라 달라지는지** 확인
* 서로 다른 두 복합명제가 **논리적으로 동치(equivalent)** 인지 증명

---

## 2. 기본 개념 정리

### (1) 명제(Proposition)

* 참(True) 또는 거짓(False) 중 하나의 값을 갖는 문장
* 보통 기호 **P, Q, R** 등으로 표현

### (2) 논리 연산자

* **¬P (not P)** : 부정
* **P ∨ Q (P or Q)** : 논리합 (하나라도 참이면 참)
* **P ∧ Q (P and Q)** : 논리곱 (둘 다 참이어야 참)
* **P → Q (P이면 Q)** : 조건명제(함의)

---

## 3. 진리표의 행(row) 개수 결정

### 핵심 원칙

> **명제의 개수가 n개이면, 행의 개수는 2ⁿ개**

이유:

* 각 명제는 **참(True) 또는 거짓(False)** 두 가지 가능성
* 모든 조합을 다 나열해야 함

#### 예시

* 명제 1개 → 2¹ = 2행
* 명제 2개 → 2² = 4행
* 명제 3개 → 2³ = 8행

---

## 4. 진리표의 열(column) 구성 원칙

진리표에는 다음과 같은 열들이 필요합니다.

1. **각 기본 명제(P, Q, R …)** 에 대한 열
2. **복합명제를 구성하는 모든 중간 표현식**에 대한 열
3. **최종 복합명제 결과**에 대한 열 (보통 맨 오른쪽)

👉 복합명제가 복잡할수록 열의 개수는 늘어납니다.

---

## 5. 연산자 우선순위 (매우 중요)

괄호가 없을 경우 반드시 다음 **연산자 우선순위**를 따릅니다.

1. ¬ (not)
2. ∧ (and)
3. ∨ (or)
4. → (if … then)

즉,

* `P ∨ Q → ¬R` 는
  **(P ∨ Q) → (¬R)** 로 해석해야 합니다.

---

## 6. 예제 1

### 복합명제:

**(P ∨ Q) → ¬R**

---

### Step 1. 기본 명제 열 생성

* 명제: **P, Q, R**
* 행의 개수: 2³ = **8행**

| P | Q | R |
| - | - | - |
| T | T | T |
| T | T | F |
| T | F | T |
| T | F | F |
| F | T | T |
| F | T | F |
| F | F | T |
| F | F | F |

> 이 부분은 **계산 없이 기계적으로 작성**합니다.

---

### Step 2. 중간 표현식 열 추가

필요한 중간 열:

* **P ∨ Q**
* **¬R**

---

### Step 3. P ∨ Q 계산

* OR(∨): **하나라도 참이면 참**

| P | Q | P ∨ Q |
| - | - | ----- |
| T | T | T     |
| T | F | T     |
| F | T | T     |
| F | F | F     |

(8행 전체에 동일한 논리 적용)

---

### Step 4. ¬R 계산

* NOT(¬): 참 ↔ 거짓 반전

| R | ¬R |
| - | -- |
| T | F  |
| F | T  |

---

### Step 5. 최종 결과: (P ∨ Q) → ¬R

#### 조건명제(→)의 핵심 규칙

* **앞이 참이고 뒤가 거짓이면 거짓**
* 그 외 모든 경우는 참

| P ∨ Q | ¬R | 결과 |
| ----- | -- | -- |
| T     | T  | T  |
| T     | F  | F  |
| F     | T  | T  |
| F     | F  | T  |

이를 8행 전체에 적용하면 최종 진리표가 완성됩니다.

---

## 7. 예제 2 (연습 문제 해설)

### 복합명제:

**(P ∨ ¬Q) → (P ∧ Q)**

---

### Step 1. 기본 명제

* 명제: **P, Q**
* 행 개수: 2² = **4행**

---

### Step 2. 필요한 중간 열

* ¬Q
* P ∨ ¬Q
* P ∧ Q

> **부정된 명제(¬Q)는 반드시 독립된 열을 만든다**
> 계산 실수를 방지하기 위한 필수 절차입니다.

---

### Step 3. 각 중간 표현식 계산

#### ¬Q

| Q | ¬Q |
| - | -- |
| T | F  |
| F | T  |

#### P ∨ ¬Q

* 하나라도 참이면 참

#### P ∧ Q

* 둘 다 참일 때만 참

---

### Step 4. 최종 조건명제 계산

* (P ∨ ¬Q)가 **참**인데 (P ∧ Q)가 **거짓** → 전체 거짓
* (P ∨ ¬Q)가 **거짓** → 결과는 무조건 참

최종 결과:

```
True, False, True, False
```

---

## 8. 핵심 정리

1. **행 개수 = 2ⁿ**
2. **모든 중간 표현식은 반드시 열로 분리**
3. **연산자 우선순위를 엄격히 적용**
4. **조건명제는 ‘앞이 참, 뒤가 거짓’만 거짓**
5. 왼쪽(기본 명제) → 가운데(부분 계산) → 오른쪽(최종 결과) 순서로 작업
이 절차를 정확히 따르면 **어떤 복합명제라도 오류 없이 진리표를 작성**할 수 있습니다.
다음 단계인 **자연어 ↔ 논리식 변환**의 기초로 매우 중요하므로, 이 구조를 반드시 숙지하시기 바랍니다.
